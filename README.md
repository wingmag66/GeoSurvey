# GeoSurvey
 📌 О проекте
Это современный одностраничный сайт (Landing Page) для компании по оказанию геодезических и кадастровых услуг. Сайт разработан с упором на высокую конверсию, удобство интерфейса и адаптивность под мобильные устройства.

### Основные функции:
- **Услуги:** Топографическая съемка, межевание, вынос границ, техпланы и др.
- **Интерактив:** Плавная прокрутка (smooth scroll), анимация появления блоков при скролле.
- **Конверсия:** Форма обратной связи с валидацией полей в реальном времени.
- **Адаптивность:** Полностью корректное отображение на смартфонах и планшетах.

## 🛠 Технологический стек
- HTML5 (семантическая верстка)
- CSS3 (переменные, Flexbox, Grid, анимации)
- JavaScript (Vanilla JS для интерактивности и валидации формы)
- Иконки: SVG (встроенные в код для быстрой загрузки)
